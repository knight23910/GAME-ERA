        🖥️ How to Install

        Step 1: Download the Game File

        Go to the game page and click the "Download" button for the game you want.

        Step 2: Locate the Downloaded File

        After downloading, find the .zip or .exe file in your Downloads folder.

        Step 3: Extract (if needed)

        If it's a .zip, right-click and choose “Extract All”.

        Step 4: Run the Installer

        Double-click Setup.exe to start installation.

        Step 5: Follow Prompts

        Choose install location and wait for it to finish.

        Step 6: Launch the Game

        Open the game from your desktop or Start menu.
